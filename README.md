
# 🌺 Terooka
### Travel Beyond Places, Into Cultures.

🏆 **Top 4 Finalist | FUSION 2026 Student Design Challenge (SDC)**

## 📖 Overview
Terooka is an interactive cultural tourism application prototype designed to enhance how travellers discover, experience and preserve Malaysia's rich cultural heritage.

By combining cultural exploration, AI-inspired interactions and personalised digital journaling, Terooka encourages travellers to go beyond sightseeing and connect with the stories and traditions behind each destination.

## ✨ Key Features

- **Cultural Discovery** – Explore heritage attractions, local traditions and cultural experiences through an interactive map.

- **AI Cultural Lens** – Discover cultural information through camera-based interactions.

- **AI Photo Guide & Captions** – Get cultural pose suggestions and AI-generated photo caption recommendations.

- **Cultural Stories** – Learn about local heritage, traditions and historical significance through interactive storytelling.

- **Digital Travel Journal** – Create and personalise digital memory books with photographs, text and decorative elements.

- **Digital Stamps** – Collect virtual stamps while exploring cultural destinations.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
